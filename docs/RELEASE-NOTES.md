## Novidades (1.2.0) – 03/10/2026

- **Migração para login com Google (segura):** fluxo guiado "pegar pela mão" para vincular conta Google mantendo todos os dados intactos (UID preservado).
- **Login duplo até 31/12/2026:** Email+Senha e Google coexistem. Após migração, Google passa a ser a forma preferencial.
- **Página de Migração dedicada:** tutorial passo a passo com coleta de Nome/Sobrenome para manter chamada/notas/boletins consistentes.
- **Termos, LGPD e ECA Digital:** botão "Termos e Políticas" na home para releitura a qualquer momento, com registro de aceite versionado.
- **Preferência por e-mail institucional:** incentivo educativo (sem bloqueio) para uso de `@estudante.sed.sc.gov.br` ou `@profe.sed.sc.gov.br`.
- **Mais segurança nas chaves:** Firebase agora lê via variáveis de ambiente (preparado para GitHub Actions). Nothing breaks: compatibilidade local mantida.
